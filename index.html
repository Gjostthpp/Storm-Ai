PRIMEIROS PASSOS

Ative seu STORM.

Comece pelo PC Windows. Depois conecte os outros aparelhos à mesma rede.

  1. Instale a central no Windows.

    Extraia o pacote, execute instalar_windows.bat e abra iniciar_storm.bat.

    Baixar para Windows (.zip)
  2. Faça o primeiro pedido.

    Digite “mostre o estado do meu PC”. Para usar a voz, execute baixar_voz_windows.bat e ative o microfone.

  3. Conecte o Linux ou o celular.

    No Windows, abra “Acesso pelo celular”. Use o endereço e o código no navegador do Android ou no cliente Linux, iniciado com bash iniciar.sh.

    Baixar para Linux Mint (.zip)

DÚVIDAS

Antes de começar.

Preciso de uma chave da OpenAI?

Os comandos locais, a voz, as notas e o diagnóstico funcionam sem chave. A conversa com o modelo de IA é opcional e usa uma chave da API configurada no Windows.

Onde o STORM escuta e fala?

Na versão 2.2, o reconhecimento integrado e a reprodução da voz ficam no Windows. O Linux e o celular enviam comandos de texto. No Android, você também pode usar o ditado do teclado.

Quais consultas precisam de internet?

Clima, notícias, Gmail e conversas com a API usam internet. Para consultar e-mails importantes no Windows, configure o Gmail e a senha de app nas preferências do STORM.
